# tri-motor_FAS_RWS_VMC_project
developing a comprehensive Vehicle Motion Control (VMC) system for a tri-motor (1F/2R) 800V pure-electric vehicle platform. The work involves authoring and maintaining a large family of formal engineering specification documents covering the full VMC function domain.  

## Edge AI engineering proposal

See [VMC Edge AI proposal](docs/edge-ai/README.md) for practical edge-model candidates, cloud updates, bounded observer corrections, interfaces and validation. The package is an engineering draft; deployment requires target benchmarks and release approval.
